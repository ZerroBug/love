# Olivia — My Miss Trouble ❤️

Created for Olivia by Anane.

## What is included
A romantic, interactive, mobile-friendly single-page website with:
- Sweet welcome
- Funny Miss Trouble investigation
- Tap-to-reveal reasons Anane loves Olivia
- A heartfelt promise
- Romantic letter
- Playful final question
- Animated hearts, sparkles and petals
- Celebration ending

## Publish on GitHub Pages
1. Create a GitHub repository named `olivia-miss-trouble`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Send Olivia the generated link.

No database or server is needed.
